# Experiments

## Summary

本文件是“当前主线”的可运行实验台账（pp.md §6 Table1 + 外部 baseline CT2Rep）。

- 旧路线/历史实验已归档：`docs/experiment_legacy_20260219.md`。
- 术语：`--saliency-weights` 是 token **score/定位**；`TokenEncoder(encoder=...)` 是 token **embedding encoder**（与 saliency 不是一件事）。
- 可比性提醒：RRG-DPO 预处理把数据落盘到统一 spacing/shape；`--resize-shape` 是额外 downsample（需在表格里明确）。
- R1（按 proposal/ECCV 偏好）主口径：`128^3`；`64^3` 与 `256^3` 仅作为 ablation。
