- Paper-grade text metrics + stats (pp.md §6.4/§6.6): run `run_baselines` with `--dump-text-pairs-jsonl`, then compute RadGraph/RaTEScore (and merge external GREEN/RadCliQ) via `python scripts/paper/compute_paper_metrics.py --text-pairs-jsonl <pairs.jsonl> --out <paper_metrics.json> --baseline-method <baseline> --holm-family all` (bootstrap CI + paired Wilcoxon + Holm).
- One-click Table1 (ours + external baselines, pp.md §6.3/§6.4): use `python scripts/paper/run_table1_ct_rate.py --manifest <manifest.jsonl> --split test --base-pairs-jsonl <pairs.jsonl> --external-pred-jsonl <preds_norm.jsonl...> --out-dir outputs/<EID> --baseline-method fixed_grid --holm-family all --n-bootstrap 10000` (add `--run-radeval` for GREEN/RadCliQ/CheXbert; add `--run-proof-external` for wrapper proof metrics).
- GREEN/RadCliQ (pp.md §6.4): use RadEval to export `extra_metrics_jsonl` via `python scripts/external/compute_radeval_metrics_jsonl.py --text-pairs-jsonl <pairs.jsonl> --out-jsonl <extra.jsonl>` (run in a Py3.11 env where RadEval is installed), then merge with `compute_paper_metrics.py --extra-metrics-jsonl <extra.jsonl>`.
- External baselines adapter (pp.md §6.3): evaluate text-only predictions with post-hoc citations via `python -m provetok.experiments.eval_external_predictions --manifest <manifest.jsonl> --pred-jsonl <preds.jsonl> --split test --budget-tokens 256 --tokenizer fixed_grid --output-dir ./outputs/<EID>`
- External baseline outputs → pred_jsonl (pp.md §6.3): use `python scripts/external/to_pred_jsonl.py --in <baseline_outputs> --format auto --method <name> --out-jsonl <preds.jsonl>` then run `python -m provetok.experiments.eval_external_predictions --manifest <manifest.jsonl> --pred-jsonl <preds.jsonl> ...`
